===== instructions =====
Stage create_node. Write one output that fits the output schema. These rules apply to its fields.

attributes
  Shape: list of at least 1 item
  strict `attributes.list@1`. List the measured attributes of the product. Why: An evaluation needs at least one measured property.
    Example: {"expected":"pass","output":[{}]}
    Example: {"expected":"fail","note":"A node needs at least one attribute.","output":[]}

attributes[]
  Shape: object with the keys amount, key, quote, unit
  strict `attributes.is_product@1`. Keep each attribute about the product itself. Why: A grade must rest on the product. A promotion or the market can change while the product stays the same.
    Example: {"expected":"pass","output":{"key":"zinc_oxide"}}
    Example: {"expected":"fail","note":"A gift with an order is a promotion, not the product.","output":{"key":"gift_sachet"}}

attributes[].amount
  Shape: number, at least 0
  strict `attributes.amount@1`. Write the amount that the label prints, as a number. Why: A grade compares amounts, so each amount must be a number.
    Example: {"expected":"pass","output":200}
    Example: {"expected":"fail","output":-1}

attributes[].key
  Shape: text of at least 1 character
  strict `attributes.key@1`. Name each attribute with a short snake_case key. Why: Logs and later stages refer to an attribute by its key.
    Example: {"expected":"pass","output":"zinc_oxide"}
    Example: {"expected":"fail","output":""}

attributes[].quote
  Shape: text of at least 1 character
  strict `attributes.quote@1`. Give the words that each attribute rests on. Why: A reader must see where each value comes from.
    Example: {"expected":"pass","output":"Zinc oxide 200 mg"}
  strict `quotes.from_label@1`. Back each attribute value with a quote from the source text. Why: A judge and a reader must find the words that the value rests on.
    Check: Copy each quote word for word from the label text, with the same letter case.
    Example: {"expected":"pass","input":{"sources":{"label":"Zinc oxide 200 mg in each gram."}},"output":"Zinc oxide 200 mg"}
    Example: {"expected":"fail","input":{"sources":{"label":"Zinc oxide 200 mg in each gram."}},"output":"zinc oxide 200mg"}
    Example: {"expected":"cannot_verify","note":"The run has no source text.","output":"Zinc oxide 200 mg"}

attributes[].unit
  Shape: text, one of: mg
  strict `units.label_unit@1`. Write the amount in the unit that the label prints. Why: A grade must rest on what the label states.
    Example: {"expected":"pass","output":"mg"}
    Example: {"expected":"fail","note":"IU is not a unit of mass.","output":"IU"}
  strict `units.mass_only@1`. Write each sunscreen active in one unit of mass. Why: One unit lets two sunscreens be compared with no conversion.
    Example: {"expected":"pass","output":"mg"}
    Example: {"expected":"fail","output":"g"}
